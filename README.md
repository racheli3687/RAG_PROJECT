# 🎓 מזכירות דיגיטלית - בוט RAG

בוט שעונה לסטודנטים על שאלות, מתוך מסמכי המכללה בלבד.
בנוי עם LlamaIndex, ‏Gemini (מסלול חינמי), ‏Chroma ו־Streamlit.

## הפעלה בפעם הראשונה

### 1. דרישות
- Python בגרסה 3.10 ומעלה. בודקים בטרמינל: `python --version`

### 2. מפתח API
1. נכנסים ל־Google AI Studio ויוצרים API Key (אם נטפרי חוסם, אפשר לבקש מהם לפתוח).
2. בתיקיית הפרויקט מעתיקים את `.env.example` לקובץ חדש בשם `.env`.
3. מדביקים את המפתח אחרי `GOOGLE_API_KEY=`.

### 3. התקנה (פעם אחת)
פותחים טרמינל בתיקיית הפרויקט:
```
python -m venv .venv
```
הפעלת הסביבה, ב־Windows:
```
.venv\Scripts\activate
```
(ב־Mac או Linux: `source .venv/bin/activate`)

ואז שתי פקודות, לפי הסדר:
```
pip install -r requirements.txt
pip install llama-index-retrievers-bm25==0.8.0 --no-deps
```
**למה בשתי פקודות?** הספרייה של BM25 דורשת גרסה ישנה של PyStemmer, שאין לה קובץ מוכן ל־Python 3.14, ולכן pip מנסה לבנות אותה ונכשל. אנחנו לא משתמשים ב"שורשים" בכלל, אז מתקינים גרסה חדשה של PyStemmer בפקודה הראשונה, ואת BM25 בלי לבדוק תלויות (`--no-deps`). pip יציג אזהרה צהובה על אי־התאמה בגרסאות. אפשר להתעלם ממנה.

### 4. בדיקת החיתוך (בלי אינטרנט ובלי מפתח)
```
python chunking.py
```
מוצגים כל הקטעים שיצאו. כדאי לעבור עליהם ולראות שהחיתוך נכון.

### 5. הפעלת הבוט
```
streamlit run app.py
```
הדפדפן נפתח בכתובת `http://localhost:8501`.
**בפעם הראשונה** הבוט בונה את המאגר (כדקה). בכל פעם אחרת הוא נטען מהדיסק תוך שניות.

## מבנה הפרויקט

| קובץ | תפקיד | שלב במסלול |
|---|---|---|
| `config.py` | כל ההחלטות מהתכנון, במקום אחד | — |
| `chunking.py` | טעינה וחיתוך המסמכים לקטעים | 1, 2 |
| `models.py` | יצירת מודל ה־Embedding ומודל התשובה | 3, 6, 9 |
| `ingest.py` | בניית המאגר: ווקטורים ל־Chroma ואינדקס מילים | 3, 4 |
| `rag.py` | חיפוש Hybrid, סף דמיון, Prompt ותשובה | 6–9 |
| `app.py` | הממשק ב־Streamlit | שאלה ותשובה |
| `data/` | מסמכי המכללה | — |
| `storage/` | נוצרת לבד: המאגר השמור | — |

הסבר מלא על הזרימה: `הסבר-המערכת.md`. הסבר על כל שורה: ההערות בתוך הקוד.

## הוספה או שינוי של מסמכים
1. שמים את הקובץ (Markdown, ‏`.md`) בתיקייה `data`.
2. בבוט, בסרגל הצד: **"בניית המאגר מחדש"**. (או בטרמינל: `python ingest.py --rebuild`)

## שאלות לבדיקה

| שאלה | מה בודקים |
|---|---|
| באיזו כיתה מתקיים CS-2104? | קוד + עדכון שסותר את הטבלה (צריך לענות 305) |
| מי מטפל בטופס 7? | מספר טופס (חיפוש לפי מילים) |
| הייתי חולה בבחינה, מה עושים? | ניסוח שונה מהמסמך (חיפוש ווקטורי) |
| מה כל הבחינות של שנה ב'? | שאלה רחבה שצריכה הרבה קטעים |
| כמה עולה תעודת סטודנט חלופית? | שאלה ממוקדת, קטע אחד |
| אפשר לגשת למועד ב' אחרי שעברתי? | כלל עם "מלכודת" (הציון האחרון קובע) |
| מה מזג האוויר מחר? | שאלה שאין עליה מידע: צריך לבקש לפרט, לא להמציא |

אחרי כל שאלה, פתחי את "מאיפה התשובה?" ובדקי אילו קטעים נמצאו ובאיזה ציון.

## כוונון
כל המספרים ב־`config.py` הם נקודת התחלה:
- **`VECTOR_MIN_COSINE`** (סף הדמיון): אם נכנסים קטעים לא קשורים, מעלים. אם קטעים נכונים חסרים, מורידים.
- **`TOP_K`**: כמה קטעים לכל היותר נשלחים למודל.
- שינוי שלהם **לא** מחייב בנייה מחדש. שינוי של `EMBED_MODEL` או של הגדרות החיתוך **כן** מחייב.

## תקלות נפוצות

| תקלה | פתרון |
|---|---|
| "חסר מפתח API" | אין קובץ `.env`, או שהשם שלו שגוי (צריך בדיוק `.env`) |
| `429` / ‏`RESOURCE_EXHAUSTED` | עברת את מגבלת המסלול החינמי לדקה. מחכים דקה ומנסים שוב |
| `API key not valid` | המפתח שגוי או בוטל. יוצרים חדש ב־Google AI Studio |
| שגיאת חיבור / Timeout | אין אינטרנט, או שנטפרי חוסם את השירות של Google |
| הבוט עונה על מסמכים ישנים | לוחצים "בניית המאגר מחדש" |
| `ModuleNotFoundError` | הסביבה (`.venv`) לא מופעלת, או שלא הורצה ההתקנה |
